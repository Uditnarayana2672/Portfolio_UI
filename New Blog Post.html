Jerry is Udit's AI-powered client representative — handling requirements, scoping, and discovery calls so no opportunity slips through. Built on LangGraph with a curated style corpus, Jerry speaks in Udit's voice and adapts to every conversation.

When I started this project, the obvious move felt like training a small language model on chat exports. That intuition turned out to be wrong, and here's why.

The trade-offs no one talks about

A 500M-parameter model fine-tuned on your WhatsApp history will sound like you. It will also forget arithmetic, fumble tool use, and confidently invent facts about your projects. The reasoning ability is the first thing to go.

✏︎
Voice without reasoning is karaoke. It mimics the surface and loses the substance. For a public-facing agent that answers technical questions, that's a non-starter.

Three layers, no training

What ended up working is a three-layer wrapper around a frontier LLM. Each layer adds a different kind of personalization without touching model weights.

1. The voice profile

A curated system prompt describing the way you talk: vocabulary preferences, opinions, conversational tics. Versioned in the database, edited from the admin panel. This is the part you can write by hand.

2. Style corpus (RAG)

A pgvector index over your writing samples — WhatsApp exports, emails, blog posts. For every visitor turn, retrieve 3-5 stylistically relevant exchanges and inject them as few-shot examples.

Python · LangGraphdef style_retriever(state: AgentState) -> AgentState:
    query = state["last_user_message"]
    samples = vector_store.similarity_search(
        query, k=5, filter={"context": state["intent"]}
    )
    state["style_examples"] = [s.page_content for s in samples]
    return state

3. Conversational memory

A graph-shaped memory in Supabase using pg_graphql + recursive CTEs. We only persist information that the Intent Classifier judges graph-worthy:

  • Entities mentioned (technologies, project names, people)
  • Stated preferences and constraints
  • Open questions waiting for follow-up
